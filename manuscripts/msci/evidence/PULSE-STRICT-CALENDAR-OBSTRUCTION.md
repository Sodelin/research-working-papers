# A source-specific obstruction at the B-to-C pulse

31 October 2026. This is a hand analysis of a **particular direct representation** of the manuscript's zero-duration pulse. It is not a proof that every graph encoding, source extension or construction of the manuscript's process is impossible. The manuscript itself is not changed. These are properties of the cited source representation, not assumptions that a different formal process must satisfy.

There is also a separate type invariant. In the [original labelled-forest source](https://raw.githubusercontent.com/Sodelin/Research-Commons/14be42189b8a72fcaced51ceda4e86445dc09e90/packages/research/vendor/accepted/predecessor-check493/source-store/d6e5b2b57cf03091f8b5b5a2c80cf49de39bab938c50a467b46b30e08f12871d.lean), an admitted sample at an edge must have an original graph path from that edge's target to its sampled tip. [Code](https://raw.githubusercontent.com/Sodelin/Research-Commons/14be42189b8a72fcaced51ceda4e86445dc09e90/packages/research/vendor/accepted/predecessor-check493/source-store/9d5a95047e3c04f9e12334cd4b5569e36e1dfa2cd4b1573f217eeb559ff9691c.lean) is an admitted snapshot. Consequently, if `target(eC)` does **not** reach the B tip, no admitted `Code` can put that B sample's current ancestor on `eC`. This follows directly from the stated descendant invariant and is conditional on the stated non-reachability.

For one concrete case, suppose `target(eC)` is the actual C tip and the sampled B and C taxa are distinct. The network source gives every tip outdegree zero and uses an injective taxon-to-tip map. A directed path from the C tip can therefore only be the empty path, ending at that same tip; it cannot reach the distinct B tip. Thus this particular terminal edge cannot carry a B sample in any admitted code, regardless of other network edges. An augmented network might use a *different* older C edge whose target can reach B; this argument does not prohibit that.

`transport_valid` alone preserves the forest invariant for a changed location; it does **not** automatically establish the separate original-descendant field required by `SourceValid`. A new B-to-C transport would need to discharge that field for all transported samples, use a suitably constructed augmented graph, or use a different state/admission interface. Merely writing a custom boundary kernel on the unchanged tree does not discharge it.

## The direct hybrid-parent interpretation

Consider only a proposed interpretation with all of these properties:

1. The B and C lineages occupy distinct original physical population edges immediately below the pulse age `h`.
2. A hybrid `H` at `h` routes a B lineage onto an actual parent edge `p` with `target(p) = H`; the existing C lineage and a routed B lineage must occupy **that same** physical edge immediately above `h`, so that the source's same-edge merger rule supplies the manuscript's immediate B/C merger opportunities.
3. Original graph routes move between incident edges at their shared vertex, using the strict calendar and its scheduled original boundaries, with no extra-time or non-graph transport.

Under these stated conditions, the direct interpretation encounters a topological conflict. Since `target(p)=H` has age `h`, `p` is not active below `h`. The pre-pulse C lineage therefore must enter `p` at `h` through `H`. Strictly positive edge durations prohibit travelling between two distinct same-age vertices along an original edge during that boundary. The C lineage's immediately younger edge must therefore have source `H`. The B lineage's immediately younger edge also has source `H`. But `H` has only one outgoing child edge, so those two edge occurrences coincide, contrary to condition 1. This is a conditional hand deduction from the listed definitions; the full path and scheduler statements still need formalization and review.

An equivalent restricted gadget test places a donor branch vertex `D` and hybrid `H` at age `h`, connected by the original parent edge `D → H`. The strict calendar would require `age(H) < age(D)`, contradicting equal ages. Distinct unconnected vertices may share an age; the contradiction concerns their proposed connecting edge.
