# Portable MSci working manuscript

This reading package was publicly released on 3 November 2026. The following
source and status statements describe the selected earlier working edition;
its original manifest and import remain available in Git history.

Start with [MANUSCRIPT.md](MANUSCRIPT.md). This local working edition includes
the manuscript and 42 selected evidence notes. The package also includes 1 source-pinned figure(s).
Sodelin organizes
and shares the working research; scientific authorship and contribution statements
remain open. This is not a Zenodo deposit, submitted preprint or peer-reviewed paper.
For a shorter introduction and specific questions for collaborators, see the
[research overview](evidence/RESEARCH-OVERVIEW-DRAFT.md).
For a plain-language explanation of the computer check, see
[what a Lean proof would mean](evidence/LEAN-EXPLAINED.md).
For the uncompiled Jacobian candidate's domain and coordinate conventions, see
the [bounded source audit](evidence/JACOBIAN-SIGNATURE-AND-COORDINATES.md).
For the distinction between the two source pulse-probability conventions, see
the [coin-convention comparison](evidence/PULSE-COIN-CONVENTION-COMPARISON.md).
For the unreviewed conditional quartet comparison and its exact arithmetic,
see the [zero-edge example](evidence/QUARTET-ZERO-EDGE-EXAMPLE.md). Its
supporting script is included; running it does not verify the biological model
or Lean proof.

The source manuscript and notes were read from local Git commit `f33ec4716ea7e4f8551d640e86494395a42fe086`.
The proof and historical review appendices are byte-for-byte unchanged from
that source. Principal-text and evidence-note links were adapted to this folder;
147 deeper internal supporting files are omitted and identified in the
affected notes and manifest. [MANIFEST.json](MANIFEST.json) records source and
output hashes. [PACKAGES.json](PACKAGES.json) adapts one editorial identity to
Sodelin from the retained source-join manifest; its guide paths do not imply
those guide files are bundled.
The asset paths in PACKAGES.json refer to the original source tree;
bundled figure paths are recorded in MANIFEST.json.

The principal and selected evidence displays use GitHub's documented
dollar-delimited mathematics. This local successor has not yet been visually
checked in a rendered Markdown view or PDF.

The reported Lean qualification covers injectivity of the selected nine-feature
analytic formula. The complete physical-process and observation proof, Jacobian
and interval checks, independent expert review, biological validation, rights and
license remain open. The [timed-genealogy note](evidence/TIMED-GENEALOGY-ORIENTATION.md)
explains one current source-to-physical-process gap; its referenced Lean files
are not included in this reading edition. A separate earlier working edition is
public on GitHub; this reading package is now publicly available here.
