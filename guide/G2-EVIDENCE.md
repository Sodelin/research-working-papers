## Question and concise argument

If a model is sampled for several individuals, does restricting the result to
some of them have the same law as running the same model for that smaller
panel? The selected G2 result answers yes under its exact finite-source,
calendar, original-parent, rate, routing and register contracts. It includes
empty and singleton selected panels. In the registered formulation the
**joint** original register is retained: the result does not replace a
correlated register with separately sampled marginals.

Full Pro's selected `kingman-restriction` unit explains a supporting step:
under the same population generator, mergers invisible after restriction
leave the restricted state unchanged, while each visible pair has the same
rate. The generator relation and semigroup identity give the corresponding
edge-level restriction. The `whole-source-projectivity` unit then requires
the same original graph, parameters and register, with the selected natural
or controlled and timed or untimed contract. This is a navigation summary of
the supplied proof chain, not a new independent proof. An intervening routing
event, newly retained input or a changed generator cannot simply be moved
across the edge by the first unit.

## What it does not establish

The law is for the specified source and permitted pruning, not inference of
an unknown source from DNA. It does not by itself prove arbitrary stopping-time
interventions, native implementation equivalence, empirical adequacy or a
timed preservation result for a G1 reduced core. Other same-clock or full-path
results require their own named sources and hypotheses. The original dated row did not itself authorize a biological experiment or external publication; this is a later authorized reading release.
