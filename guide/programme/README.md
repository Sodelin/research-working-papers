# Working programme reading guide

This twelve-chapter guide gathers existing AI-assisted research into a single place for readers who want to see the arguments, their assumptions and the connections between projects. It was adapted on 3 November 2026 from the scientific-library owner's dated local reading draft. Sodelin directs and organizes the broader project; source-specific mathematical and AI contributions are attributed in the individual materials.

This is a **working reading guide**, not a collection of independently accepted theorems or a count of novel discoveries. Its compact arguments often use named suppliers; they are not necessarily self-contained proofs. Reported Lean results cover only their stated components, and internal AI review is not independent human peer review. Statements and status labels reflect their source epochs, may have been superseded, and require source-specific checking. In particular, the original general G3 and G4 questions remain open.

## Source availability

Where a chapter's local citation was not selected for this public edition and could not be bound to an existing public source, its link has been replaced with a link to this note. The source is **not included**; the statement should be assessed using the other cited public evidence or by obtaining that source. This is not evidence the missing source was wrong or verified. The [source manifest](SOURCE-MANIFEST.json) gives the original and adapted SHA-256 for each selected text and counts such references.

The adaptation changes mathematical display delimiters for GitHub, routes available citations to immutable public versions, substitutes the project's chosen public name where needed, and marks unavailable local citations. Chapter 8 also omits one inherited link whose target's sharing status is unverified; the earlier public Git version still contains it. It does not supply a missing proof, perform a new build or establish a new review. See the collection's [source notes](../../PROVENANCE.md) for the exact owner revision and release history.
