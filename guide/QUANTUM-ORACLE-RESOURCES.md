# Oracle synthesis: charging the implementation and preserving phase

Aaronson–Kuperberg's [2007 paper](https://theoryofcomputing.org/articles/v003a007/) poses the unitary-synthesis question in its final discussion. The [5 October 2026 OpenAI preprint](https://github.com/openai/math/blob/fd4aeeb2ee4fc729c18d98444fed42fd0529eeeb/preprints/Polynomial-Time-Unitary-Synthesis-from-a-Boolean-Oracle-October-5-2026/paper.pdf), attributed to OpenAI in its source README and TeX, reports a positive answer to the constant-error formulation. That result is not claimed as Sodelin's or as independently audited here.

The retained [on-demand quantitative theorem](https://github.com/Sodelin/Research-Commons/blob/27b143c73a4ac272b560b2974d83ff96df738531/research/2026-10-09-dot-quantum-oracle-resource-audit-1544z/ON-DEMAND-ORACLE-QUANTITATIVE-THEOREM.md), attributed to dot (OpenAI), assumes the preprint's specified constructive results. For dense algebraic unitary entries with explicit polynomial coefficient lists and isolating intervals, it supplies a canonical deterministic oracle evaluator terminating per address, with a coarse, enormous classical bit-time bound. It does not materialize all recursive siblings or the truth table. Polynomial unit-cost oracle-skeleton size does not make that classical evaluator efficient, and dense-input length must be counted.

The [phase-sensitive transfer note](https://github.com/Sodelin/Research-Commons/blob/27b143c73a4ac272b560b2974d83ff96df738531/research/2026-10-09-dot-quantum-oracle-resource-audit-1544z/PHASE-SENSITIVE-TRANSFER-COST-AND-OBSTRUCTION.md) charges classical preprocessing, expanded evaluator gates and workspace. It requires uniform coherent error, including arbitrary answer bits and uncomputation. Average classical answer success is insufficient. A program simulation with a common isometric encoder requires generator/pulse intertwining and phase control; a classical observation-law projection alone does not supply it. Counting permutation channels gives a standard fully charged implementation obstruction, compatible with the different unit-cost oracle model and dense-input scaling.

What this does: turns an oracle-level statement into an explicit conditional implementation/resource contract and prevents a classical law-preserving adapter from being used as a coherent quantum encoder. A concrete useful follow-on is specialist correspondence and choosing a meaningful evaluator/representation regime. No efficient general implementation, new synthesis resolution, physical device result or general classical-to-quantum transfer follows.
